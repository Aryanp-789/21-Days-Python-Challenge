## 📖 File Modes

| Mode | Description                                   |
| ---- | --------------------------------------------- |
| `r`  | Read a file                                   |
| `w`  | Write to a file (overwrites existing content) |
| `a`  | Append data to a file                         |
| `r+` | Read and write                                |
| `w+` | Read and write (creates/overwrites file)      |
| `a+` | Read and append                               |

---

## 💡 Key Concepts

* Open files using `open()`
* Always close files after use
* Prefer `with open()` because it closes files automatically
* Read entire files or line by line
* Write and append data safely
* Handle missing files using exceptions
