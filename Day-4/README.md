# Day 4 - Conditional Statements in Python

## Introduction

Conditional statements allow a program to make decisions based on different conditions. They help control the flow of execution by running specific blocks of code only when certain conditions are true.

---

## Topics Covered

- if Statement
- if-else Statement
- if-elif-else Statement
- Nested if Statements
- Comparison Operators
- Logical Operators

---

## Syntax

### if Statement

```python
if condition:
    # code to execute
```

### if-else Statement

```python
if condition:
    # code to execute if true
else:
    # code to execute if false
```

### if-elif-else Statement

```python
if condition1:
    # code block 1
elif condition2:
    # code block 2
else:
    # code block 3
```
