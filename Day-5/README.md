## break Statement

The `break` statement immediately terminates a loop when a specific condition is met.

Example:

```python
for i in range(10):
    if i == 5:
        break
    print(i)
```

---

## continue Statement

The `continue` statement skips the current iteration and moves to the next iteration.

Example:

```python
for i in range(10):
    if i == 5:
        continue
    print(i)
```
